# Задание для браузерной сессии Claude Code (смена темы Blogger)

Эта сессия получает управление **твоим реальным Chrome** через **Chrome DevTools
MCP** (по CDP, без Playwright, без отдельного браузера — с твоим логином Blogger).
Используется для того, что НЕ доступно через Blogger API: смена темы, раскладка,
гаджеты.

──────────────────────────────────────────────────────────────────────────────
## Как запустить (PowerShell, из папки проекта)

```powershell
cd c:\project\github\ourgoodrecipes

# 1. Один раз: добавить Chrome DevTools MCP в Claude Code
claude mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest --autoConnect

# 2. В Chrome включить отладку: открыть chrome://inspect/#remote-debugging
#    → поставить галочку "Enable remote debugging" → Allow

# 3. Запустить сессию Claude в этой папке
claude
```

Способ A (выше, `--autoConnect`, Chrome 144+) цепляется к твоему **уже открытому**
Chrome с залогиненным Blogger — повторный вход не нужен.

Если autoConnect недоступен — способ B (через порт):
```powershell
# закрыть Chrome, затем:
& "C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\Users\Petrosyan\chrome-debug"
# и добавить MCP с указанием URL:
claude mcp add chrome-devtools -- npx -y chrome-devtools-mcp@latest --browserUrl=http://127.0.0.1:9222
```
⚠️ У способа B свой `--user-data-dir` = свежий профиль, Blogger там надо
залогинить один раз. Для сохранения логина удобнее способ A.

> Плюс: это обычная Claude Code сессия в этой папке — она и Chrome водит, и
> читает файлы проекта (`AICONTEXT.md`, `category_widget.html`,
> `blogger_token.json`).

──────────────────────────────────────────────────────────────────────────────
## ПРОМПТ (скопировать в новую сессию целиком)

Ты — Claude Code с управлением моим реальным Chrome через Chrome DevTools MCP.
У меня в этом Chrome уже залогинен Blogger. СНАЧАЛА прочитай `AICONTEXT.md` в этой
папке — там вся история проекта, ID блога, метки и что уже сделано.

Контекст: блог `ourgoodrecipes.blogspot.com` (тема Blogger «Contempo»). Через API
уже сделано (НЕ ломать!): оформленные карточки рецептов внутри постов, метки на
всех 99 постах (18 меток), страница-оглавление `/p/blog-page.html`. Всё это живёт
в контенте/настройках и от темы не зависит.

ЗАДАЧА — то, что нельзя через API (только UI Blogger в браузере):
1. Открой в управляемом Chrome `https://www.blogger.com` (я уже залогинен).
   Выбери блог «Рецепты … соли и глютена».
2. **СНАЧАЛА сделай резервную копию темы:** Тема → стрелка вниз → «Создать
   резервную копию» → скачать XML. Это обязательный первый шаг.
3. Согласуй со мной, КУДА переходим:
   - вариант безопасный: встроенная тема **Emporio** (картиночная, под рецепты);
   - вариант «food»: сторонняя бесплатная тема (Foodicious/Pepper и т.п.) — если
     я даю XML/ссылку, СНАЧАЛА вычитай XML на вредные скрипты, редиректы,
     обфускацию и скрытые ссылки, и только потом ставь.
4. Поставь выбранную тему (Тема → выбрать / Изменить HTML → вставить XML).
5. Сделай категории видимыми НА ГЛАВНОЙ (не сворачивающийся сайдбар):
   - возьми готовый блок из файла `category_widget.html` в этой папке (или с живой
     страницы `/p/blog-page.html`);
   - добавь его как гаджет **HTML/JavaScript** (Макет → Добавить гаджет) как можно
     выше, либо вставь в шаблон перед лентой постов (id='Blog1');
   - старый сворачивающийся гаджет **«Ярлыки»** удали.
6. Если осталась Contempo/встроенная — применить кастомный CSS (Тема → Настроить →
   Дополнительно → Добавить CSS); палитра: акцент #c0392b, фон #fffaf7, тёплые
   «таблетки»-метки (CSS-сниппет — в истории проекта/у меня).
7. Проверь результат на живом сайте (открой главную, кликни плитку-категорию —
   должна открыться `/search/label/<метка>`). Покажи скрин/итог.

ПРАВИЛА:
- Любое необратимое/видимое действие (смена темы, удаление гаджета, «Сохранить»)
  — только ПОСЛЕ резервной копии и моего подтверждения.
- НЕ трогай контент постов, метки и страницу-оглавление — они уже готовы.
- Для проверок данных блога (посты/метки) можно использовать Blogger API:
  токен в `blogger_token.json`, примеры вызовов — в `blogger_format.mjs`.
- Действуй пошагово, показывай, что видишь в браузере, перед кликами по
  «Сохранить/Применить» спрашивай подтверждение.

Начни с чтения `AICONTEXT.md`, затем открой Blogger и предложи план.
